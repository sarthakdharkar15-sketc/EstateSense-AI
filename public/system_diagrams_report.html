This report provides the system architecture, data models, controls, and states for the **EstateSense AI House Price Prediction Platform with Explainable AI (SHAP)**.

Description of Use Cases:

  • Register & Authenticate: Users can create an account and log in. An administrator has special elevated roles.
  • View Project Dashboard: Displays general information, performance curves, global feature importance charts, and key stats.
  • Predict House Price: Input area, bedrooms, bathrooms, location, age, parking, type, and furnishing state to calculate expected valuations.
  • Interpret Local SHAP Explanations: Explains why the prediction was made, breaking down the exact pricing contribution of each feature.
  • Explore Spatial Map Analysis: Inspects geographically plotted properties on the city map (Bengaluru coordinates) and filters them.
  • Compare Model Performance: Views metrics (MAE, RMSE, R2, MAPE) of baseline vs. ML models.
  • Upload Custom Dataset (Admin): Allows uploading of custom property CSV files to fit the prediction model.
  • Train/Retrain Model (Admin): Dynamically recalculates weights, coefficients, and validation metrics.
